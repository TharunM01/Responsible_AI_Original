===========================================================================
  HOW TO RUN  (only needed if you want to regenerate figures)
===========================================================================

  Step 1 — Install Python 3.8+ from python.org
            Tick "Add Python to PATH" during install

  Step 2 — Open Command Prompt (Windows) or Terminal (Mac/Linux)

  Step 3 — Install packages (one time only):
    pip install lightgbm xgboost shap lime imbalanced-learn scipy scikit-learn pandas numpy matplotlib seaborn openpyxl

  Step 4 — Navigate to code folder:
    cd Desktop\RAI_PROJECT\code

  Step 5 — Run:
    python credit_default_run.py

  Step 6 — Wait 5-10 minutes. All figures saved to output_figures\

  NOTE: You do NOT need to run the code. All 29 figures are
        already pre-generated in the figures\ folder.

# Temporal Behavioral Feature Engineering for Explainable Credit Default Prediction

Explainable AI pipeline for credit default prediction combining 13 novel temporal behavioral features with a gradient boosting model (LightGBM/XGBoost), dual SHAP+LIME explainability, and an automated regulatory-compliance layer (GDPR Article 22, ECOA, Basel III, FRB SR 11-7).

**Author:** Tharun M
**Paper (preprint):** https://doi.org/10.5281/zenodo.23098510

## Key result
LightGBM achieves ROC-AUC = 0.9866 on a synthetic benchmark matched to the UCI Default of Credit Card Clients dataset. The most predictive engineered feature is RSI (Repayment Sufficiency Index), a novel contribution of this work.

## Contents
- credit_default_run.py — main pipeline script (data generation, feature engineering, model training, SHAP/LIME explainability, fairness audit, regulatory report generation)
- output_figures/ — all 25 figures generated by the pipeline (ROC curves, SHAP plots, fairness analysis, etc.)
- results_summary.json / results_summary.txt — model performance and SHAP feature rankings from a real run
- requirements.txt — Python dependencies

## Note on dataset
All results use a synthetic dataset constructed to match the documented marginal distributions and conditional default probabilities of the publicly available UCI Default of Credit Card Clients dataset (Yeh & Lien, 2009). No real customer financial data was used.
